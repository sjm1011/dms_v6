DMS 文件管理系統 V6 - 使用者功能規格說明書

本說明書旨在為一般使用者、部門主管與系統管理同仁提供「DMS 文件管理系統 V6（DMS V6）」之功能導覽與操作規範。本系統採用純網頁架構，免安裝任何用戶端軟體，即可在兼顧便利性與高度資訊安全的前提下，進行文件的儲存、共享、版本控管與審查。

---

1. 使用者角色與權限說明

系統採用「基於資料夾的權限控制機制（ACL）」，將使用者分為三種角色：

1.1. 一般使用者（USER）

  • 基本權限：可瀏覽自己權限範圍內之資料夾、檢索文件、線上預覽與下載授權檔案。
  • 限制：無法變更資料夾結構、無法調整他人權限，且對於 PDF 格式之正式發布文件，僅限線上預覽，不開放直接下載檔案。

1.2. 資料夾管理員（Folder Manager）

  • 身分說明：為計算型的管理身分。當同仁被系統管理員指派為某資料夾之管理員時，該同仁便自動擁有該資料夾及其子目錄的管理權限。
  • 管理權限：
    • 可在負責的資料夾下新增、修改、移動、封存或刪除子資料夾。
    • 可設定負責資料夾的存取控制表（ACL），指派哪些部門（群組）或特定同仁可以讀取該資料夾。
    • 可在該資料夾下建立新文件、上傳新版本，或發布修訂對照表。

1.3. 系統管理員（ADMIN）

  • 最高權限：具備系統最高管理權限，可進入系統後台進行全域設定。
  • 專屬功能：包含指派或撤銷各資料夾管理員、查詢全域操作稽核軌跡（Audit Log），以及進行系統層級之維護。

2. 資料夾分類與管理

系統中的資料夾分為兩種存取類型，並提供完整的生命週期管理：

2.1. 資料夾存取分類

  • 公開資料夾：系統內所有已登入的同仁皆可直接瀏覽與檢索其中的文件。
  • 限閱資料夾：必須由該資料夾管理員設定存取控制（ACL）授權。僅有被明確指派的部門（群組）或特定同仁，在登入後才能看見此資料夾與其中的文件。若未獲授權，一般同仁在介面上將完全無法察覺該資料夾之存在。

2.2. 資料夾生命週期

  • 新增與異動：資料夾管理員可隨時調整資料夾的名稱與位置（移動資料夾）。
  • 封存資料夾：當整個資料夾的階段任務結束時，管理員可對其進行「封存」。
    • 唯讀保護：封存後的資料夾及其所有子資料夾將進入唯讀狀態，同仁無法再於其下新增資料夾或上傳文件。
    • 文件自動廢止：封存動作會自動將資料夾下所有原本有效的文件全部變更為「廢止」狀態，以防止舊文件被誤用。
  • 刪除資料夾：僅有當資料夾內部完全沒有任何子資料夾與文件（空目錄）時，管理員才可執行刪除動作。

3. 文件管理與版本控管

DMS V6 核心特色為「文件主檔與版本分離」之設計，確保文件的演進歷史與使用狀態能被嚴格追蹤：

3.1. 文件的生命週期狀態

  • 主檔狀態：
    • 有效：文件處於正常使用狀態，同仁可檢索並讀取其最新生效的版本。
    • 廢止：文件已失效。廢止後，一般使用者在系統中將無法再搜尋或預覽此文件。
  • 版本推導狀態：
    • 文件不設人工狀態欄位，而是由系統自動依據「生效時間」、「結束時間」與「是否撤回」來自動推導目前有效之版本。

3.2. 核心操作功能

A. 新建文件與發布

  • 新建文件時，必須輸入系統唯一的文件編號（全系統不重複）、文件名稱，並上傳正式發布檔案。

B. 文件版更與預約生效

  • 當文件內容異動時，管理員可為同一文件主檔上傳「新版本」。
  • 預約生效：上傳新版本時，管理員可指定未來的「生效時間」（預約版本）。
    • 新舊交替：在預約時間到達前，一般使用者仍會看到目前的舊版本；一旦時間到達，系統會自動切換新版本生效，並自動更新舊版本的結束時間，無須人工手動下架。
    • 同一時間只能存在一個尚未生效的預約版本。

C. 撤回版本（回復前版）

  • 若發現最新發布（或預約發布）的版本內容有誤，管理員可執行「撤回」。
  • 撤回後，該錯誤版本即刻失效，系統會自動清除前一版本的結束時間，使其重新恢復為「最新有效版本」，確保業務流程不中斷。

D. 手動廢止文件

  • 當文件不再適用時，管理員可手動將其廢止。
  • 廢止時，管理員必須提供廢止公文檔案（需符合系統檔案角色），並填寫廢止原因，以供日後審查。

4. 檔案預覽與下載之安全規範

為了防止機密文件外洩，系統針對不同的檔案格式與使用者權限設定了極為嚴格的資安限制：

4.1. PDF 文件線上預覽限制

  • 僅限線上預覽：所有正式發布之 PDF 文件，一般使用者僅能線上查閱，系統完全屏蔽並禁用下載功能。
  • 動態安全浮水印：當使用者開啟 PDF 預覽時，系統會自動在後端將該同仁的「使用者帳號」、「姓名」以及「查閱時間」動態生成為浮水印，並重疊渲染於 PDF 畫面上。若同仁意圖以拍照或螢幕截圖方式外流檔案，將能直接追溯洩漏源頭。

4.2. 非 PDF 文件下載規範

  • 對於非 PDF 格式之檔案（如 Word、Excel 等），系統允許獲授權之同仁下載至本機端進行編輯，但所有下載行為皆會留下完整紀錄。

4.3. 修訂對照表

  • 為了讓同仁快速掌握新舊版本的差異，管理員在進行文件版更時，可以選擇性上傳「修訂對照表檔案」（如標明差異的 Word 比較檔）。
  • 一般同仁在瀏覽文件時，可同步開啟此對照表，快速掌握文件異動重點。

5. 全域稽核與操作軌跡

系統記錄所有人的操作軌跡，以保障文件資產安全：

5.1. 稽核紀錄範圍

系統會自動且即時記錄下列所有事件：

  • 登入與登出：包含登入成功、登入失敗之嘗試。
  • 文件瀏覽與預覽：記錄誰在何時預覽了哪份文件的哪一個版本。
  • 文件下載：記錄所有檔案的下載操作。
  • 文件生命週期異動：包括新建、上傳新版、預約版、撤回、手動廢止等。
  • 資料夾與權限調整：記錄資料夾的建立、移動、封存，以及 ACL 存取權限的指派與撤銷。
  • 安全性拒絕：記錄任何因權限不足而被拒絕存取或下載的失敗操作。

5.2. 不可竄改原則

  • 追加寫入模式：所有稽核紀錄僅能由系統後端自動追加寫入。
  • 禁用修改與刪除：系統介面與 API 皆不提供任何修改或刪除稽核紀錄的功能，以確保日後資安稽核與軌跡追蹤之真實性。
