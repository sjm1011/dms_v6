# DMS 文件管理系統 - 系統管理員說明書

本說明書提供負責 DMS 全站設定、第一層資料夾、管理員指派、系統檢查及資源回收作業的人員使用。

---

## 1. 系統管理員的工作範圍

系統管理員可以：

- 建立第一層資料夾。
- 管理全站資料夾及其開放方式。
- 指派、更換或撤銷第一層資料夾管理員。
- 處理協同管理員的例外異動。
- 管理根目錄文件。
- 管理一般及敏感文件。
- 查看全部系統稽核紀錄。
- 設定系統管理員。
- 查看權限總覽及系統狀態。
- 還原或永久刪除封存資料。

## 2. 機密文件例外

系統管理員的全站權限不會自動開放機密文件。

系統管理員必須同時被有效指派為文件所在資料夾的資料夾管理員或協同管理員，才能：

- 在清單或搜尋結果看到機密文件。
- 預覽或下載機密文件。
- 修改、版更、撤回、刪除、廢止或移動機密文件。

未具備資料夾管理身分時，系統會拒絕操作並留下紀錄。

## 3. 登入與系統管理選單

### 3.1. 登入

1. 開啟 DMS 網址。
2. 輸入「使用者帳號」及「密碼」。
3. 選取「登入系統」。

### 3.2. 確認系統管理員身分

登入後，左側使用者資訊會顯示「系統管理員」。

角色異動必須重新登入才會生效。

### 3.3. 系統管理選單

左側「系統管理」依序提供：

1. 系統稽核紀錄。
2. 系統設定。
3. 權限總覽。
4. 系統狀態。
5. 資源回收區。

開啟系統管理頁面時，不會載入文件清單。返回文件庫後，系統會保留原本的資料夾位置。

### 3.4. 輸入畫面的操作方式

- 開啟輸入畫面後，游標會停在第一個可輸入欄位。
- 在不是最後一個輸入欄位按下 `Enter`，游標會移到下一個欄位。
- 在最後一個輸入欄位按下 `Enter`，才會執行主要確認按鈕。
- 使用中文輸入法選字時，按下 `Enter` 不會送出表單。
- 必填欄位未完成時，系統會顯示訊息並將游標移回需要補填的欄位。
- 權限設定等重要畫面不能以點擊背景的方式關閉，請使用「取消」或完成儲存。

## 4. 根目錄與第一層資料夾

### 4.1. 根目錄

只有系統管理員可以在根目錄：

- 建立第一層資料夾。
- 建立文件。
- 修改、版更、廢止或維護根目錄文件。

根目錄中已生效的「一般」及「敏感」文件，所有已登入使用者都可以查看。

根目錄文件不能設定為「機密」，也不能移入或移出。

### 4.2. 建立第一層資料夾

1. 回到文件庫根目錄。
2. 選取「新增資料夾」。
3. 輸入資料夾名稱。
4. 選取確認按鈕。
5. 建立完成後，在「屬性設定」選擇開放方式。

建立完成時可以暫時不指派資料夾管理員。未指派期間仍由系統管理員管理。

### 4.3. 修改第一層資料夾

開啟資料夾操作選單後，可以使用：

- 「修改資料夾」：修改資料夾名稱。
- 「屬性設定」：設定公開、限閱或僅限管理者。
- 「刪除（作廢）」：刪除空資料夾。
- 「封存資料夾」：封存仍有內容的資料夾。

「修改資料夾」只會修改名稱，不會移動資料夾位置。

## 5. 指派資料夾管理員

每個第一層資料夾同一時間最多只能有 1 位資料夾管理員，也可以維持未指派。

### 5.1. 指派或更換

1. 進入第一層資料夾或其子資料夾。
2. 選取畫面上方的「管理員」。
3. 輸入員工編號。
4. 確認畫面顯示正確姓名。
5. 儲存設定。

尚未指派時，畫面會顯示紅色「管理員：未指派」。

### 5.2. 撤銷

1. 開啟資料夾管理員設定。
2. 清除目前管理員。
3. 儲存設定。

撤銷後，該人員會立即失去資料夾管理功能及該範圍稽核紀錄查詢權。

### 5.3. 協同管理員例外處理

系統管理員可以在必要時指派或撤銷協同管理員。

設定只會修改目前資料夾直接指派的人員，不會移除由上層資料夾繼承的協同管理員。

## 6. 資料夾開放方式

| 狀態 | 說明 |
| --- | --- |
| 公開 | 所有已登入同仁都可以進入。 |
| 限閱 | 被授權部門、同仁及有效管理員可以進入。 |
| 僅限管理者 | 只有系統管理員及有效管理員可以進入。 |

系統管理員不受一般資料夾限閱名單限制，但機密文件仍需具備有效資料夾管理身分。

上層資料夾為「限閱」或「僅限管理者」時，子資料夾會繼承該限制，不能自行放寬。

限閱至少需要 1 個有效部門或同仁，否則系統會阻擋儲存。

## 7. 文件管理

### 7.1. 根目錄文件

只有系統管理員可以在根目錄建立及維護文件。

根目錄文件：

- 只能選擇「一般」或「敏感」。
- 不能設定為「機密」。
- 不能移入或移出根目錄。
- 已生效後對所有已登入使用者公開。

### 7.2. 資料夾內文件

系統管理員可以管理一般及敏感文件，包括：

- 新增文件及相關文件。
- 修改文件資料。
- 上傳新版。
- 刪除預約版本。
- 查看版本歷史。
- 撤回已生效的最新版本。
- 刪除符合條件的第一版文件。
- 手動廢止文件。
- 移動文件。

機密文件仍依第 2 節限制。

系統管理員可以在根目錄將文件設定為「一般」或「敏感」。一般資料夾內既有文件的機敏等級，只有目前有效的資料夾管理員或協同管理員可以變更。

### 7.3. 重要限制

- 同一份文件同一時間只能有 1 個預約版本。
- 預約版本應使用「刪除預約版本」取消。
- 撤回最新版本後，前一版會恢復為目前有效版本。
- 廢止文件後不能再版更或撤回。
- 移動文件必須同時具備來源及目的資料夾的管理權。

完整的資料夾及文件操作步驟，請參考「文件管理員說明書」。

## 8. 系統稽核紀錄

### 8.1. 可以查看的範圍

系統管理員可以查看全部稽核紀錄，包括：

- 登入成功及失敗。
- 資料夾與權限異動。
- 文件建立、修改、版更、撤回、刪除、廢止及移動。
- 文件預覽及下載。
- 無權限、已廢止或無效版本的存取嘗試。
- 系統管理員異動。
- 稽核紀錄匯出。
- 資料夾還原及永久刪除。

### 8.2. 查詢

1. 展開左側「系統管理」。
2. 選取「系統稽核紀錄」。
3. 設定日期、操作者、稽核事件、執行結果或關鍵字。
4. 執行查詢。

預設查詢最近 1 個月，每頁可選擇 25、50 或 100 筆。

清單顯示：

- 事件時間。
- 操作者。
- 稽核事件。
- 資源位置。
- 操作標的。
- 執行結果。

選取「明細」可以查看事件來源、原因、異動前後資料及其他調查資訊。

### 8.3. 匯出

匯出會沿用目前查詢條件。資料超過 50,000 筆時，請先縮小日期或查詢範圍。

匯出操作本身也會留下紀錄。

### 8.4. 紀錄保護

系統畫面不提供修改或刪除稽核紀錄的功能。

## 9. 系統設定

目前「系統設定」只提供系統管理員設定。

### 9.1. 指定系統管理員

1. 開啟「系統設定」。
2. 選取「指定系統管理員」。
3. 輸入員工編號。
4. 確認顯示正確姓名。
5. 儲存設定。

對象必須是系統中存在且仍在職的員工。

### 9.2. 撤銷系統管理員

1. 在系統管理員清單找到目標人員。
2. 選取「撤銷」。
3. 確認操作。

系統不允許：

- 撤銷自己的系統管理員權限。
- 撤銷最後 1 位有效系統管理員。

新增或撤銷後，對象必須重新登入，角色才會更新。

## 10. 權限總覽

「權限總覽」以唯讀方式顯示第一層資料夾的：

- 主要管理員。
- 協同管理員。
- 開放方式。
- 限閱授權摘要。
- 子資料夾數量。
- 文件數量。

可以依資料夾名稱、缺少主要管理員或開放方式篩選。

需要修改時，選取「前往資料夾」，再由文件庫中的資料夾畫面操作。

## 11. 系統狀態

「系統狀態」提供唯讀資訊：

- 應用程式版本、環境、伺服器時間及執行時間。
- 資料庫連線、版本、查詢時間及連線使用狀況。
- 儲存空間位置、讀寫狀態、容量及剩餘空間。
- 重要設定是否完整或安全。
- 有效及封存資料夾、文件、版本、管理員及稽核紀錄統計。
- 待清理及失敗的檔案清理工作。

頁面不會顯示資料庫密碼或系統密鑰。

選取「重新整理」可以取得最新狀態。

## 12. 資源回收區

### 12.1. 還原封存資料夾

1. 開啟「資源回收區」。
2. 找到要還原的封存資料夾。
3. 選取「還原」。
4. 確認還原。

還原會包含同一次封存的子資料夾。只有因資料夾封存而自動廢止的文件會恢復；原本手動廢止的文件不會恢復。

### 12.2. 永久刪除

執行前提：

- 資料夾已封存滿 90 天。
- 已確認不再需要還原。

操作步驟：

1. 找到可永久刪除的封存資料夾。
2. 選取「永久刪除」。
3. 輸入完整資料夾名稱。
4. 再次確認影響範圍。
5. 執行永久刪除。

永久刪除會作廢資料及檔案資料，並刪除實體檔案。完成後無法從系統畫面還原。

> 重要提醒：永久刪除是不可復原操作。執行前必須確認封存日期、資料夾名稱、子資料夾、文件及檔案數量。

### 12.3. 重試檔案清理

如果資料已作廢，但實體檔案清理尚未完成，資源回收區會顯示待清理工作。

選取「重試清理」後，系統會繼續刪除已隔離的檔案。

## 13. 常見狀況

### 13.1. 無法查看機密文件

請確認目前帳號是否同時被指派為該資料夾的資料夾管理員或協同管理員。只有系統管理員身分仍不足以查看機密文件。

### 13.2. 無法撤銷系統管理員

不能撤銷自己，也不能撤銷最後 1 位有效系統管理員。

### 13.3. 角色異動後畫面沒有改變

系統管理員角色保存在登入狀態中。請讓對象登出後重新登入。

### 13.4. 無法永久刪除

請確認資料夾已封存滿 90 天，且輸入的資料夾名稱完全相同。

### 13.5. 還原後部分文件仍是廢止

手動廢止的文件不會因還原資料夾而恢復。只有封存時由系統自動廢止的文件會恢復。

### 13.6. 系統狀態顯示異常

先選取「重新整理」確認最新狀態，再依異常項目檢查應用程式、資料庫、儲存空間或重要設定。問題回報時應提供異常項目及發生時間，不應傳送密碼或密鑰。

## 14. 高風險操作檢查

執行下列操作前，必須確認目標及影響範圍：

| 操作 | 必須確認 |
| --- | --- |
| 撤銷資料夾管理員 | 對象會立即失去管理及稽核查詢權。 |
| 封存資料夾 | 全部子資料夾及文件都會受到影響。 |
| 撤回版本 | 前一版會恢復為目前有效版本。 |
| 刪除文件 | 文件及符合條件的版本資料會移除。 |
| 廢止文件 | 文件不再提供一般使用者查閱，也不能繼續版更。 |
| 移動文件 | 文件可見範圍會改依目的資料夾計算。 |
| 撤銷系統管理員 | 對象重新登入後失去全站管理權。 |
| 永久刪除 | 實體檔案會刪除，無法由系統畫面還原。 |

## 15. 操作安全

- 不得共用系統管理員帳號。
- 不得將密碼、系統密鑰或資料庫連線資料放入問題回報內容。
- 權限異動應確認員工編號及姓名一致。
- 永久刪除前應依組織規定確認保存期限及備份。
- 系統會記錄管理員設定、權限異動、資料夾生命週期及文件操作。
