# DMS 文件管理系統：系統管理員說明書

本說明書提供負責 DMS 全站設定、第一層資料夾、管理員指派、系統檢查及資源回收作業的人員使用。

一般查閱操作請參考[一般使用者說明書](一般使用者說明書.md)；完整的資料夾與文件操作步驟請參考[文件管理員說明書](文件管理員說明書.md)。

## 1. 權限原則

### 1.1. 系統管理員工作範圍

系統管理員可以：

- 建立第一層資料夾。
- 管理全站資料夾及其開放方式。
- 指派、更換或撤銷第一層資料夾管理員。
- 處理協同管理員的例外異動。
- 管理根目錄文件，以及一般或敏感文件。
- 查看全部系統稽核紀錄。
- 設定系統管理員及管理公告。
- 查看權限總覽及系統狀態。
- 還原或永久刪除封存資料。

### 1.2. 機密文件例外

系統管理員的全站權限不會自動開放機密文件。

系統管理員必須同時被有效指派為文件所在資料夾的資料夾管理員或協同管理員，才能：

- 在清單或搜尋結果看到機密文件。
- 預覽或下載機密文件。
- 修改、版更、撤回、刪除、廢止或移動機密文件。

未具備資料夾管理身分時，系統會拒絕操作並留下紀錄。

## 2. 登入與主畫面

### 2.1. 登入與確認身分

1. 開啟 DMS 網址。
2. 輸入「使用者帳號」及「密碼」。
3. 按一下「登入系統」。
4. 登入後，確認左側使用者資訊顯示「系統管理員」。

系統管理員角色異動後，對象必須登出再重新登入，角色才會更新。

### 2.2. 儀表板

登入成功後會先顯示「儀表板」。左側主導覽依序為「儀表板」、「文件庫」及「系統管理」。

系統管理員的儀表板除了公告及「近期發佈的文件」，也會顯示下列系統異常摘要：

- 資料庫連線失敗。
- 儲存空間無法讀寫。
- 必要設定缺漏。
- 連線池等待。
- 待清理工作及失敗工作。

按一下異常項目，可前往「系統狀態」或「資源回收區」查看。儀表板不會顯示儲存根目錄、資料庫版本或原始錯誤內容。

系統管理員若同時是有效的資料夾管理員或協同管理員，「預約發佈提醒」還會顯示目前管理範圍內，未來 30 天將發佈的版本。只有系統管理員身分而沒有資料夾管理指派時，不會顯示此區塊，也不會因此取得機密文件。

### 2.3. 系統管理選單

左側「系統管理」依序提供：

1. 系統稽核紀錄。
2. 系統設定。
3. 權限總覽。
4. 系統狀態。
5. 資源回收區。

開啟系統管理頁面時，不會載入文件清單。返回文件庫後，系統會保留原本的資料夾位置。

### 2.4. 輸入畫面操作方式

- 開啟後，游標會停在第一個可輸入欄位。
- 在非最後一個輸入欄位按下 `Enter`，游標會移到下一個欄位。
- 在最後一個輸入欄位按下 `Enter`，才會執行主要確認按鈕。
- 使用中文輸入法選字時，按下 `Enter` 不會送出表單。
- 必填欄位未完成時，系統會顯示訊息，並將游標移回需要補填的欄位。
- 權限設定等重要畫面不能按一下背景區域關閉，請使用「取消」或完成儲存。

## 3. 第一層資料夾與管理員

### 3.1. 建立第一層資料夾

#### 操作前確認

只有系統管理員可以在文件庫根目錄建立第一層資料夾。

#### 操作步驟

1. 回到文件庫根目錄。
2. 按一下「新增資料夾」。
3. 輸入資料夾名稱。
4. 按一下確認按鈕。
5. 建立完成後，在「屬性設定」選擇開放方式。

#### 完成結果

建立完成時可以暫時不指派資料夾管理員。未指派期間仍由系統管理員管理。

### 3.2. 指派或更換資料夾管理員

#### 操作前確認

每個第一層資料夾同一時間最多只能有 1 位資料夾管理員，也可以維持未指派。

#### 操作步驟

1. 進入第一層資料夾或其子資料夾。
2. 按一下畫面上方的「管理員」。
3. 輸入員工編號。
4. 確認畫面顯示正確姓名。
5. 儲存設定。

尚未指派時，畫面會顯示紅色「管理員：未指派」。

### 3.3. 撤銷資料夾管理員

1. 開啟資料夾管理員設定。
2. 清除目前管理員。
3. 儲存設定。

撤銷後，該人員會立即失去資料夾管理功能及該範圍稽核紀錄查詢權。

### 3.4. 協同管理員例外處理

系統管理員可以在必要時指派或撤銷協同管理員。

設定只會修改目前資料夾直接指派的人員，不會移除由上層資料夾繼承的協同管理員。

## 4. 資料夾與文件管理

### 4.1. 資料夾開放方式

| 狀態 | 可以進入的人員 |
| --- | --- |
| 公開 | 所有已登入同仁。 |
| 限閱 | 被授權部門、同仁及有效管理員。 |
| 僅限管理者 | 系統管理員及有效管理員。 |

- 系統管理員不受一般資料夾限閱名單限制，但機密文件仍需具備有效資料夾管理身分。
- 上層資料夾為「限閱」或「僅限管理者」時，子資料夾會繼承該限制，不能自行放寬。
- 限閱至少需要 1 個有效部門或同仁，否則系統會阻擋儲存。

開啟資料夾操作選單後，可以使用：

- 「修改資料夾」：修改資料夾名稱，不會移動資料夾位置。
- 「屬性設定」：設定公開、限閱或僅限管理者。
- 「刪除（作廢）」：刪除空資料夾。
- 「封存資料夾」：封存仍有內容的資料夾。

### 4.2. 根目錄文件

只有系統管理員可以在根目錄建立及維護文件。

| 規則 | 說明 |
| --- | --- |
| 機敏等級 | 只能選擇「一般」或「敏感」，不能設定為「機密」。 |
| 可見範圍 | 已生效後，所有已登入使用者都可以查看。 |
| 移動限制 | 不能移入或移出根目錄。 |

### 4.3. 一般資料夾內文件

系統管理員可以管理一般及敏感文件，包括：

- 新增文件及相關文件。
- 修改文件資料。
- 下載 PDF 原始編修檔案，並於「修改文件」中新增或替換原始編修檔案。
- 上傳新版或刪除預約版本。
- 查看版本歷史或撤回已生效的最新版本。
- 刪除符合條件的第一版文件。
- 手動廢止或移動文件。

一般資料夾內既有文件的機敏等級，只有目前有效的資料夾管理員或協同管理員可以變更。機密文件仍依[1.2. 機密文件例外](#12-機密文件例外)限制。

完整操作步驟及版本限制，請參考[文件管理員說明書](文件管理員說明書.md)。

## 5. 系統稽核紀錄

### 5.1. 查閱範圍

系統管理員可以查看全部稽核紀錄，包括：

- 登入成功及失敗。
- 資料夾與權限異動。
- 文件建立、修改、版更、撤回、刪除、廢止及移動。
- 文件預覽及下載。
- 無權限、已廢止或無效版本的存取嘗試。
- 系統管理員異動。
- 公告建立、修改、發佈及封存。
- 稽核紀錄匯出。
- 資料夾還原及永久刪除。

### 5.2. 查詢

1. 展開左側「系統管理」。
2. 按一下「系統稽核紀錄」。
3. 設定日期、操作者、稽核事件、執行結果或關鍵字。
4. 執行查詢。

預設查詢最近 1 個月，每頁可選擇 25、50 或 100 筆。

清單顯示：

- 事件時間。
- 操作者。
- 稽核事件。
- 資源位置。
- 操作標的。
- 執行結果。

按一下「明細」，可查看事件來源、原因、異動前後資料及其他調查資訊。

### 5.3. 匯出與紀錄保護

- 匯出會沿用目前查詢條件。
- 資料超過 50,000 筆時，請先縮小日期或查詢範圍。
- 匯出操作本身也會留下紀錄。
- 系統畫面不提供修改或刪除稽核紀錄的功能。

## 6. 系統設定

目前「系統設定」提供系統管理員設定及公告管理。

### 6.1. 指定系統管理員

1. 開啟「系統設定」。
2. 按一下「指定系統管理員」。
3. 輸入員工編號。
4. 確認顯示正確姓名。
5. 儲存設定。

對象必須是系統中存在且仍在職的員工。

### 6.2. 撤銷系統管理員

1. 在系統管理員清單找到目標人員。
2. 按一下「撤銷」。
3. 確認操作。

系統不允許撤銷自己的系統管理員權限，也不允許撤銷最後 1 位有效系統管理員。新增或撤銷後，對象必須重新登入，角色才會更新。

### 6.3. 建立公告草稿或發佈公告

1. 開啟「系統設定」。
2. 在「公告管理」按一下「新增公告」。
3. 輸入標題及純文字內容。標題最多 120 字，內容最多 2000 字；在內容欄按下 `Shift + Enter` 可換行，顯示時會保留換行。
4. 選擇「一般」、「重要」或「緊急」。
5. 選擇公告對象。
6. 視需要設定發佈時間及下架時間。
7. 按一下「儲存草稿」或「發佈」。

未指定未來發佈時間時，公告發佈後立即生效；指定未來時間時，公告會在該時間起顯示。下架時間必須晚於發佈時間。

公告對象可選：

- 全體使用者。
- 系統管理員。
- 資料夾管理員及協同管理員。

選擇「全體使用者」時，不得同時選擇其他角色。系統管理員與資料夾管理員對象可以同時選擇。

### 6.4. 修改或封存公告

- 草稿可修改後儲存或發佈。
- 已發佈公告可修改內容、重要程度、對象及時間。修改後版次會增加，所有對象需重新將新版標示為已讀。
- 兩位管理員同時修改同一公告時，較晚送出的舊版次操作會被拒絕；請重新載入後再修改。
- 「封存」只會將公告改為唯讀，不會實體刪除。已封存公告不能重新發佈。
- 公告發佈及下架會依畫面查詢時間自動生效，不需要另外執行排程工作。

## 7. 權限總覽與系統狀態

### 7.1. 權限總覽

「權限總覽」以唯讀方式顯示第一層資料夾的：

- 主要管理員及協同管理員。
- 開放方式及限閱授權摘要。
- 子資料夾數量及文件數量。

可以依資料夾名稱、缺少主要管理員或開放方式篩選。需要修改時，按一下「前往資料夾」，再由文件庫中的資料夾畫面操作。

### 7.2. 系統狀態

「系統狀態」提供下列唯讀資訊：

- 應用程式版本、環境、伺服器時間及執行時間。
- 資料庫連線、版本、查詢時間及連線使用狀況。
- 儲存空間位置、讀寫狀態、容量及剩餘空間。
- 重要設定是否完整或安全。
- 有效及封存資料夾、文件、版本、管理員及稽核紀錄統計。
- 待清理及失敗的檔案清理工作。

頁面不會顯示資料庫密碼或系統密鑰。按一下「重新整理」可取得最新狀態。

## 8. 資源回收區

### 8.1. 還原封存資料夾

1. 開啟「資源回收區」。
2. 找到要還原的封存資料夾。
3. 按一下「還原」。
4. 確認還原。

還原會包含同一次封存的子資料夾。只有因資料夾封存而自動廢止的文件會恢復；原本手動廢止的文件不會恢復。

### 8.2. 永久刪除

#### 操作前確認

- 資料夾已封存滿 90 天。
- 已確認不再需要還原。

#### 操作步驟

1. 找到可永久刪除的封存資料夾。
2. 按一下「永久刪除」。
3. 輸入完整資料夾名稱。
4. 再次確認影響範圍。
5. 執行永久刪除。

#### 完成結果

永久刪除會作廢資料及檔案資料，並刪除實體檔案。完成後無法從系統畫面還原。

> 重要提醒：永久刪除是不可復原操作。執行前必須確認封存日期、資料夾名稱、子資料夾、文件及檔案數量。

### 8.3. 重試檔案清理

如果資料已作廢，但實體檔案清理尚未完成，資源回收區會顯示待清理工作。

按一下「重試清理」後，系統會繼續刪除已隔離的檔案。

## 9. 常見狀況

| 狀況 | 請確認 |
| --- | --- |
| 無法查看機密文件 | 目前帳號是否同時被指派為該資料夾的資料夾管理員或協同管理員。 |
| 無法撤銷系統管理員 | 不能撤銷自己，也不能撤銷最後 1 位有效系統管理員。 |
| 角色異動後畫面沒有改變 | 請讓對象登出後重新登入。 |
| 無法永久刪除 | 資料夾是否已封存滿 90 天，且輸入的資料夾名稱是否完全相同。 |
| 還原後部分文件仍是廢止 | 手動廢止的文件不會恢復，只有封存時由系統自動廢止的文件會恢復。 |
| 系統狀態顯示異常 | 先按一下「重新整理」，再依異常項目檢查應用程式、資料庫、儲存空間或重要設定。 |
| 系統更新後無法啟動 | 請部署人員確認正式環境的 Session Secret 已設定為至少 32 字元的專用隨機字串，且未沿用範例或提示文字。 |
| 使用者回報找不到實體檔案 | 請確認檔案位於目前儲存根目錄或已設定的舊檔根目錄內；不得為解決單筆舊檔而放寬整體路徑範圍。 |

問題回報時應提供異常項目及發生時間，不應傳送密碼或密鑰。

## 10. 高風險操作檢查

| 操作 | 執行前必須確認 |
| --- | --- |
| 撤銷資料夾管理員 | 對象會立即失去管理及稽核查詢權。 |
| 封存資料夾 | 全部子資料夾及文件都會受到影響。 |
| 撤回版本 | 前一版會恢復為目前有效版本。 |
| 刪除文件 | 文件及符合條件的版本資料會移除。 |
| 廢止文件 | 文件不再提供一般使用者查閱，也不能繼續版更。 |
| 移動文件 | 文件可見範圍會依目的資料夾計算。 |
| 撤銷系統管理員 | 對象重新登入後失去全站管理權。 |
| 永久刪除 | 實體檔案會刪除，無法由系統畫面還原。 |

- 不得共用系統管理員帳號。
- 不得將密碼、系統密鑰或資料庫連線資料放入問題回報內容。
- 權限異動應確認員工編號及姓名一致。
- 永久刪除前應依組織規定確認保存期限及備份。
- 系統會記錄管理員設定、權限異動、資料夾生命週期及文件操作。
