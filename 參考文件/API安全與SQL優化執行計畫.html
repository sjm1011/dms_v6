3. 執行管制

3.1 每一批的固定流程

  1. 確認本批次範圍與使用者修改內容。
  2. 檢查工作目錄，避免覆蓋既有未提交變更。
  3. 僅修改本批次列出的檔案。
  4. 執行檔案範圍檢查及 TypeScript 檢查。
  5. 從 dmsV6 執行 npm run build。
  6. 執行本批次列出的 API 或資料庫驗證。
  7. 回報變更檔案、驗證結果及剩餘風險。
  8. 使用者確認後，才進入下一批。

3.2 停止條件

遇到下列情況時，不得自行擴大修改範圍：

  • 商業規則與現有程式行為衝突。
  • 需要修改共用的 employee.emp_pw 密碼格式。
  • 需要刪除正式文件或資料庫資料。
  • 需要變更 IIS、VPN、防火牆或正式網域。
  • 需要新增尚未核准的 PostgreSQL 資料表。
  • 建置失敗且根因不在本批次修改範圍。
  • 發現使用者尚未提交的變更與預計修改內容重疊。

發生錯誤時，必須使用以下格式回報：

Status：
Root Cause：
Suggested Fix：

4. 實作前待確認事項

開始對應批次前，需由使用者填寫或確認下列決策。

D-01：發佈檔案大小上限

  • 決定值：100 MB
  • 建議同時限制 Base64 解碼後大小及 HTTP Request Body 大小。

D-02：來源檔案大小上限

  • 決定值：100 MB

D-03：HTML 預覽策略

  • [x] 決定：取消 HTML、HTM、MHTML 類型的檔案上傳及預覽。
  • [ ] A. 保留預覽，但使用 CSP Sandbox 禁止 JavaScript、表單、導向及外部連線。
  • [ ] B. 停止 HTML、HTM、MHTML 線上預覽，只允許下載。
  • [ ] C. 改由獨立且不帶 DMS Session Cookie 的預覽網域提供。

建議選擇 A；若 HTML 內容必須執行 JavaScript，改選 C。

D-04：敏感操作的稽核寫入失敗策略

  • [x] A. 稽核寫入失敗時，文件刪除、ACL 修改及封存一併回復。
  • [ ] B. 主操作繼續，但必須寫入伺服器錯誤日誌及系統事件紀錄。

建議選擇 A。

D-05：伺服器端 Session 資料表

  • [ ] 同意新增 Session 資料表。
  • [x] 暫時維持目前簽章 Cookie，只先移除預設密鑰並補強驗證。

D-06：MD5 密碼遷移

  • [ ] employee.emp_pw 僅供 DMS 使用，可以規劃遷移。
  • [ ] employee.emp_pw 由其他 Delphi 系統共用，暫不修改。
  • [x] 尚未確認，必須先調查。

    • 狀態：不執行

    • 狀態：不執行

8.3 Session 資料表規則

若 D-05 同意新增資料表，需符合：

  • [ ] 不建立 Foreign Key。
  • [ ] 不建立額外 Constraint。
  • [ ] Session ID 只保存雜湊值。
  • [ ] 保存使用者帳號。
  • [ ] 保存建立時間與到期時間。
  • [ ] 保存最後活動時間。
  • [ ] 保存撤銷時間與撤銷原因。
  • [ ] 保存 IP 及 User-Agent 摘要。
  • [ ] 建立必要的普通索引，不在索引內做型別轉換。

8.4 執行項目

  • [ ] Cookie 只保存隨機 Session ID。
  • [ ] API 每次由 PostgreSQL 驗證 Session。
  • [ ] 敏感操作重新取得目前使用者角色。
  • [ ] 登出立即撤銷 Session。
  • [ ] 離職、停權或權限取消後舊 Session 不再有效。
  • [ ] 正式環境缺少必要 Session 設定時停止啟動。
  • [ ] HTTPS 環境使用 Secure Cookie。
  • [ ] Session Cookie 維持 HttpOnly。
  • [ ] 加入帳號及 IP 單位的登入失敗限制。
  • [ ] 加入短時間連續失敗延遲。
  • [ ] 加入暫時鎖定及自動解鎖時間。
  • [ ] 登入成功後清除失敗計數。
  • [ ] 登入成功、失敗、鎖定及撤銷均寫入稽核。

8.5 驗證項目

  • [ ] 偽造 Session ID 無法登入。
  • [ ] 登出後舊 Session 無法繼續使用。
  • [ ] 權限取消後舊 Session 無法維持原權限。
  • [ ] 過期 Session 被拒絕。
  • [ ] 達到失敗次數後登入受到限制。
  • [ ] 不同 IP 與不同帳號的限流規則正確。
  • [ ] npm run build 成功。
