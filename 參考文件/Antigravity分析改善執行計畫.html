2. 不變條件

  • 單一檔案上限維持 100 MB。
  • 允許的檔案格式、ACL、文件狀態、文件生命週期及既有稽核事件語意不變。
  • 不新增 PRIMARY KEY、FOREIGN KEY 或額外 CONSTRAINT。
  • 每個 Node.js 執行個體最多同時處理 2 筆上傳；額滿時回傳 HTTP 503 與 Retry-After: 5。
  • 含檔案操作統一使用 POST /api/documents/upload?action=<action>；POST /api/documents 只保留純 JSON 操作。

8. 未完成事項與停止條件

  • 路徑盤點發現合法舊檔位於允許根目錄外時，必須先設定 Legacy Root 或搬移檔案，不得放寬程式邊界。
