DMS 文件管理系統 使用者說明書

本說明書依據現行系統功能規格編寫，提供一般使用者、資料夾管理員、協同管理員及系統管理員操作 DMS 文件管理系統 時使用。

---

1. 系統用途

DMS 用於保存已完成簽核的正式文件，並管理文件的版本、生效日期、查閱權限、下載、撤回與廢止紀錄。

DMS 不處理文件擬稿、會簽或核准流程。文件應於現行流程中完成簽核或確認，再由具備管理權限的人員上傳至 DMS。

---

2. 使用者身分與可用功能

2.1. 一般使用者

一般使用者可執行下列操作：

  • 瀏覽有權限的資料夾。
  • 搜尋有權限的資料夾與文件。
  • 查看目前生效中的文件。
  • 線上預覽及下載 PDF 文件 (有浮水印)。
  • 預覽及下載瀏覽器支援的圖檔。
  • 下載其他非 PDF 文件。
  • 查看目前可見版本的修訂對照表。

一般使用者無法查看尚未生效、歷史、已撤回或已廢止的文件版本，也無法建立、修改、版更、撤回或廢止文件。

2.2. 資料夾管理員

資料夾管理員由系統管理員指派至第一層資料夾，其管理權會涵蓋該資料夾及其全部子資料夾。

資料夾管理員可在管理範圍內執行下列操作：

  • 建立及修改子資料夾。
  • 設定資料夾為「公開」或「限閱」。
  • 指派或撤銷協同管理員。
  • 建立文件及上傳新版。
  • 查看版本歷史與尚未生效版本。
  • 撤回最新版本並回復前版。
  • 下載 PDF 正式原檔及歷史版本檔案。
  • 上傳及下載 PDF 原始編修檔案。
  • 刪除符合條件的第一版文件。
  • 手動廢止文件。
  • 刪除空資料夾或封存非空資料夾。

2.3. 協同管理員

協同管理員從被指派的資料夾開始，管理該資料夾及其全部子資料夾。協同管理員具備資料夾與文件管理功能，但不能指派、撤銷或變更任何資料夾管理員或協同管理員。

2.4. 系統管理員

系統管理員具備全站管理權限，可建立第一層資料夾、管理所有資料夾與文件、設定第一層資料夾管理員，以及處理協同管理員的例外異動。

根目錄及第一層資料夾的管理限制如下：

  • 只有系統管理員可建立第一層資料夾。
  • 只有系統管理員可在根目錄建立、版更、廢止或維護文件。
  • 根目錄中已生效的文件對所有已登入使用者公開。

3. 登入與登出

3.1. 登入系統

  1. 開啟 DMS 網址。
  2. 在「使用者帳號」欄位輸入帳號。
  3. 在「密碼」欄位輸入密碼。
  4. 選取「登入系統」。

登入失敗時，系統會顯示錯誤訊息、清空帳號與密碼，並將輸入焦點移回「使用者帳號」。請依錯誤訊息重新輸入。

3.2. 登出系統

選取左側使用者資訊區旁的「登出」按鈕。登出後，系統會清除目前登入狀態並返回登入畫面。

3.3. 登入憑證失效

登入憑證逾期或失效時，系統會顯示「登入憑證失效」。關閉訊息視窗後，系統會返回登入畫面，請重新登入。

---

4. 主畫面導覽

4.1. 左側資料夾樹

左側資料夾樹顯示目前帳號可見的資料夾。選取資料夾後，右側清單會顯示該資料夾直屬的子資料夾與文件。

已封存或已刪除的資料夾不會出現在一般文件庫中。

4.2. 文件與資料夾清單

清單中的資料夾會顯示其存取狀態：

  • 「公開」：所有已登入使用者皆可進入。
  • 「限閱」：只有系統管理員、有效管理員、被授權部門成員或被授權同仁可進入。

一般使用者只會看到目前生效且有權限查閱的文件。具備管理權限的人員可額外看到尚未生效版本及管理功能。

「文件編號」欄位也會顯示目前登入者本人的資料夾管理身分：

  • 金色盾牌圖示：代表目前帳號是該資料夾的主要管理員。
  • 藍色雙人圖示：代表目前帳號是該資料夾或其上層資料夾指派的協同管理員。
  • 資料夾列依該資料夾的有效管理身分顯示；文件列依文件所屬資料夾的有效管理身分顯示。
  • 將滑鼠移至圖示上方，可查看「您是此資料夾的管理員」或「您是此資料夾的協同管理員」提示。
  • 系統管理員的全站管理權本身不會顯示圖示；若系統管理員同時被正式指派為主要管理員或協同管理員，仍會顯示相應圖示。
  • 沒有被指派資料夾管理身分的使用者不會顯示任何管理身分圖示。

4.3. 搜尋資料夾或文件

  1. 在上方「搜尋資料夾或文件」欄位輸入關鍵字。
  2. 系統會依目前可見內容篩選資料夾與文件。
  3. 清除關鍵字即可恢復完整清單。

搜尋不會顯示無權限、尚未生效、歷史、已撤回或已廢止的文件資訊。

4.4. 操作選單

每筆資料夾或文件右側提供操作選單。選單內容會依使用者身分、資料狀態及管理權限顯示；未出現的操作代表目前帳號或資料狀態不符合執行條件。

---

5. 共用輸入操作

系統輸入畫面會以對話框顯示，操作方式如下：

  • 開啟對話框後，輸入焦點會位於第一個可編輯欄位。
  • 在非最後一個輸入欄位按下 Enter，焦點會移至下一個可編輯欄位。
  • 在最後一個輸入欄位按下 Enter，才會執行主要確認按鈕。
  • 使用中文輸入法組字時，按下 Enter 只會完成組字，不會切換欄位或提交。
  • 必填欄位未填寫時，系統會顯示明確的錯誤訊息。關閉訊息後，焦點會回到第一個未完成欄位。
  • 權限設定等重要對話框不能以點擊背景的方式關閉，請使用「取消」或完成儲存。

---

6. 文件查閱、預覽與下載

6.1. PDF 文件

一般使用者操作方式：

  1. 開啟文件的操作選單。
  2. 選取「線上預覽 PDF」。
  3. 系統會在 PDF 每一頁加入浮水印後開啟預覽。

浮水印包含使用者姓名與帳號、預覽時間、用戶端 IP、文件編號及「內部文件，禁止外流」。預覽產生的浮水印不會修改伺服器上的正式原檔。

一般使用者不能下載 PDF 正式原檔。如需紙本，可使用瀏覽器提供的列印功能。具備文件管理權限的人員可從操作選單選取「下載正式 PDF」。

6.2. 圖檔

JPG、JPEG、PNG、GIF 及 WebP 圖檔提供開新視窗預覽及下載：

  1. 開啟文件的操作選單。
  2. 選取「開新視窗預覽」查看圖檔。
  3. 如需保存檔案，選取「下載正式檔案」。

TIF 與 TIFF 因主流瀏覽器未提供一致的原生顯示能力，僅提供下載。圖檔預覽不會套用浮水印。

6.3. 其他非 PDF 文件

Word、Excel 與 PowerPoint 不提供線上預覽。請開啟文件的操作選單，選取「下載正式檔案」。

一般使用者只能下載目前生效中的最新版。具備文件管理權限的人員可從版本歷史下載其他有權限的版本。

6.4. 修訂對照表

具備文件查閱權限的使用者，可查看目前可見版本的修訂對照表。修訂對照表用於說明修訂章節、修訂前後內容、原因及備註，不取代正式發佈檔案。

7. 資料夾管理

本節功能只對系統管理員、資料夾管理員或協同管理員顯示，並以各自的有效管理範圍為限。

7.1. 建立資料夾

  1. 進入要建立子資料夾的位置。
  2. 選取「新建資料夾」。
  3. 輸入資料夾名稱。
  4. 完成畫面要求的管理設定。
  5. 選取確認按鈕完成建立。

第一層資料夾只能由系統管理員在根目錄建立。新建資料夾預設為「限閱」；未設定授權部門或同仁前，只有系統管理員與有效管理員可見。

7.2. 修改資料夾

  1. 開啟目標資料夾的操作選單。
  2. 選取「修改資料夾」。
  3. 修改允許變更的資料。
  4. 儲存變更。

7.3. 設定公開或限閱

  1. 開啟目標資料夾的操作選單。
  2. 選取「屬性設定」。
  3. 選擇「公開」或「限閱」。
  4. 若選擇「限閱」，可勾選一個以上的授權部門，並可逐筆輸入特定同仁的員工編號。
  5. 確認同仁姓名驗證成功後，選取「確定儲存」。

輸入特定同仁時：

  • 輸入員工編號後按下 Enter 或離開欄位，系統會查詢姓名。
  • 驗證成功後，系統會顯示姓名並新增下一個空白輸入列。
  • 查無同仁或尚未完成驗證時，系統會阻擋儲存。

資料夾沒有權限設定紀錄不代表公開。只有明確設定為「公開」時，一般使用者才能瀏覽。

7.4. 指派資料夾管理員

每個第一層資料夾同一時間最多只能有 1 名資料夾管理員。

系統管理員進入尚未指派管理員的資料夾時，畫面上方會顯示紅色「管理員：未指派」。選取該欄位可開啟指派畫面。完成員工編號驗證後儲存，即可指派管理員；將欄位留空後儲存，代表撤銷指派。

7.5. 指派協同管理員

系統管理員或第一層資料夾管理員可執行下列操作：

  1. 進入要設定協同管理員的資料夾。
  2. 選取畫面上方的「協同管理員」欄位。
  3. 輸入一位或多位同仁的員工編號。
  4. 確認每筆姓名驗證成功。
  5. 儲存設定。

此畫面只修改目前資料夾直接指派的協同管理員，不會移除從上層資料夾繼承的協同管理員。協同管理員只能查看有效管理員姓名，不能開啟指派功能。

7.6. 刪除空資料夾

資料夾內沒有正常狀態的子資料夾及有效文件時，操作選單會顯示「刪除（作廢）」。

  1. 開啟目標資料夾的操作選單。
  2. 選取「刪除（作廢）」。
  3. 確認資料夾名稱與警告內容。
  4. 選取「確認刪除（作廢）」。

7.7. 封存非空資料夾

資料夾內仍有正常子資料夾或有效文件時，操作選單會顯示「封存資料夾」。

  1. 開啟目標資料夾的操作選單。
  2. 選取「封存資料夾」。
  3. 閱讀封存影響警告。
  4. 選取「確認封存」。

封存會產生下列結果：

  • 目前資料夾及全部子資料夾會一併封存。
  • 資料夾下的所有文件會自動廢止。
  • 封存內容會從一般文件庫移除。
  • 實體檔案與歷史紀錄仍會保留。

封存後項目會移至系統管理員的資源回收區；執行前仍應確認目標資料夾及其全部內容。

8. 文件建立與版本管理

8.1. 新建文件

  1. 進入文件要存放的資料夾。
  2. 選取「新建文件」。
  3. 視需要填寫文件編號；文件編號可留空。
  4. 視需要填寫版本號；版本號可留空。
  5. 填寫文件名稱。
  6. 選擇正式發佈的文件檔案。
  7. 選擇修訂日期與生效日期。
  8. 選取常用異動說明，或直接輸入自訂內容。
  9. 正式發佈檔案為 PDF 時，可選擇上傳「PDF 原始編修檔案」。
  10. 選取「上傳建檔」。

生效日期預設為當日：

  • 選擇當日，建檔完成後立即生效。
  • 選擇未來日期，該版本會在指定日期 00:00:00 生效。

尚未生效前，一般使用者看不到該文件；具備管理權限的人員可以查看。

文件編號有填寫時，系統會自動轉為大寫。文件編號不可與其他文件重複；未編號文件可於「修改文件」補填，既有文件編號也可修改或清空。

8.2. 可上傳的檔案格式

正式發佈檔案支援下列格式：

  • PDF：.pdf
  • Word：.docx、.doc
  • Excel：.xlsx、.xls
  • PowerPoint：.pptx、.ppt
  • 圖檔：.jpg、.jpeg、.png、.gif、.tif、.tiff、.webp

檔案大小上限為 100 MB。系統會拒絕空檔案、偽裝副檔名、無法辨識的檔案，以及巨集、執行檔、腳本、安裝檔、捷徑或壓縮檔。

8.3. 上傳新版

  1. 開啟目標文件的操作選單。
  2. 選取「上傳新版」。
  3. 視需要填寫新版本號。
  4. 選擇新版正式發佈檔案。
  5. 選擇修訂日期與生效日期。
  6. 選取或輸入異動說明。
  7. 新版為 PDF 時，可選擇上傳 PDF 原始編修檔案。
  8. 選取「建立新版」。

若新版排定於未來生效：

  • 生效前，一般使用者仍會看到上一個有效版本。
  • 到達生效時間後，系統會自動改為顯示新版。
  • 同一份文件同一時間只能有 1 個尚未生效的預約版本。

若已有預約版本，必須先撤回該版本，才能建立另一個預約版本。

8.4. 查看版本歷史

  1. 開啟目標文件的操作選單。
  2. 選取「版本歷史」。
  3. 查看各版本的版本號、修訂日期、生效狀態及相關檔案。

具備管理權限的人員可查看尚未生效、歷史及已撤回版本，並依權限下載正式檔案或 PDF 原始編修檔案。

8.5. 撤回最新版本並回復前版

此功能只適用於最新一筆尚未撤回的版本，且文件必須有前一版可供回復。

  1. 開啟目標文件的操作選單。
  2. 選取「撤回最新版本」。
  3. 輸入撤回原因。
  4. 選取「撤回並回復前版」。

撤回後：

  • 一般使用者會改為看到前一個版本。
  • 被撤回版本及其檔案、異動說明與修訂紀錄會永久保留。
  • 已撤回版本不能重新啟用。如需再次使用相同內容，必須重新建立新版。

8.6. 刪除第一版文件

文件只有第 1 版，且仍符合系統刪除條件時，操作選單會顯示「刪除文件」。

  1. 開啟文件操作選單。
  2. 選取「刪除文件」。
  3. 確認文件名稱與警告內容。
  4. 選取「確認刪除」。

刪除後，文件主檔與第一版紀錄會移除，但系統仍會保留稽核紀錄。

8.7. 手動廢止文件

文件已有多個版本時，操作選單會依狀態提供「廢止文件」。

  1. 開啟目標文件的操作選單。
  2. 選取「廢止文件」。
  3. 輸入廢止原因。
  4. 上傳廢止公文或核准文件。
  5. 選取「確認廢止」。

廢止後，一般使用者不再看到該文件。已廢止文件不能再上傳新版、預約生效或撤回版本。如需重新發行，應建立新文件。

9. 常見狀況處理

9.1. 看不到資料夾

依序確認下列項目：

  1. 資料夾是否已設定為「公開」。
  2. 若為「限閱」，目前帳號所屬部門或員工編號是否已被授權。
  3. 資料夾是否已封存或刪除。

若仍無法確認，請聯絡該資料夾管理員或系統管理員。

9.2. 看不到文件或新版

依序確認下列項目：

  1. 文件或新版是否尚未到生效日期。
  2. 文件是否已廢止。
  3. 最新版本是否已撤回。
  4. 所屬資料夾是否已封存。
  5. 目前帳號是否具備該資料夾的查閱權限。

一般使用者只能看到目前時間落在有效期間內的版本。

9.3. 沒有出現管理操作

操作選單會依後端判定的權限與資料狀態顯示。沒有出現「新建資料夾」、「新建文件」、「上傳新版」或「屬性設定」時，代表目前帳號在該位置沒有對應管理權，或資料狀態不允許該操作。

9.4. 無法儲存限閱名單

若特定同仁欄位顯示查無使用者或尚未驗證，系統會阻擋儲存。請確認員工編號正確，並按下 Enter 或移出該欄位完成姓名驗證。

9.5. 無法上傳檔案

請確認下列項目：

  1. 檔案格式是否在允許清單內。
  2. 檔案是否超過 100 MB。
  3. 檔案是否為 0 byte 空檔案。
  4. 副檔名是否與實際檔案格式一致。
  5. 是否已選擇所有必填日期並填寫異動說明。

9.6. PDF 沒有下載按鈕
